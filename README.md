# Planejamento Financeiro para Advogadas

Landing page de Yale Barbosa, planejadora financeira (CPRO-R), para advogadas que ganham bem e querem transformar renda em patrimônio.

A página é um único arquivo (`index.html`), com imagens embutidas, e pode ser publicada direto pelo GitHub Pages. `og.jpg` é a imagem de prévia do link (WhatsApp, redes sociais).
